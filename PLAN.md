# primex A prime number explorer

* Typescript, using Google coding style.
* npm, vite
* Compile to a single self-contained index.html for deployment

Tasks
[ ] App stub, compiles index.html
[ ] Color scheme is basically black on white. Thin black border around the square image. Non-prime squares are white, primes are black.
[ ] Prime number generator.
[ ] Image creator, params are scale, origin. Image height=width=2^scale. Origin is the lower left quarter image.
[ ] Default view scale=8, origin=2
[ ] Navigation.
